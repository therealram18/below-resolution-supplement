# Env: harness/envs/toto  (python 3.11)
# Model: Datadog/Toto-Open-Base-1.0 via the DataDog/toto GitHub repo (this is
# Toto 1.0, NOT the `toto-2` PyPI package used by Toto 2.0 -- gift-eval's
# notebooks/toto.ipynb is the Toto-1.0 reference; notebooks/toto_2_0.ipynb is
# a different model).
#
# Repo is vendored (not pip-installed from PyPI) at harness/vendor/toto,
# cloned from https://github.com/DataDog/toto (commit recorded in
# harness/README.md). It ships its own requirements.txt (pins gluonts[torch]
# ==0.16.2, torch==2.7.0) which conflicts with gift-eval's gluonts~=0.15.1 --
# same shape of conflict as moirai2. Fix: install toto's requirements.txt
# first, then gift-eval, which downgrades gluonts to 0.15.1 for compatibility.
# Verified `toto.model.toto`, `toto.inference.gluonts_predictor` and
# `gift_eval.data` all import cleanly together afterward (import check only).
#
# Repo layout note: notebooks/toto.ipynb imports `from model.toto import
# Toto`, which assumes `toto/toto` itself is on sys.path -- that breaks
# ("attempted relative import beyond top-level package") because
# toto/model/toto.py uses relative imports (`from ..model.attention import
# ...`) that need the `toto` package intact. The repo's own pyproject.toml
# (package name `toto-ts`) installs `toto` as a proper top-level package when
# you `pip install -e` the repo ROOT (harness/vendor/toto), which is what we
# do below -- then import as `from toto.model.toto import Toto` and
# `from toto.inference.gluonts_predictor import TotoPredictor, Multivariate`
# (see harness/run_grid.py).
#
# setuptools>=81 removed the `pkg_resources` module, which gluonts.torch ->
# lightning.fabric still imports at load time -- this broke the import chain
# (ModuleNotFoundError: No module named 'pkg_resources') until setuptools was
# pinned back below 81. Pin this explicitly; don't assume the ambient
# setuptools version.
#
# Install:
#   uv venv envs/toto --python 3.11
#   uv pip install --python envs/toto/bin/python -r ../vendor/toto/requirements.txt
#   uv pip install --python envs/toto/bin/python -e ../gift-eval
#   uv pip install --python envs/toto/bin/python -e ../vendor/toto --no-deps
#   uv pip install --python envs/toto/bin/python "setuptools<81" --reinstall
setuptools<81
